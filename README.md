# InsightIQ Business Analytics Dashboard

A responsive, standalone business analytics dashboard demo. The page includes KPI cards, a revenue trend chart, traffic source visualization, product performance, recent transactions, responsive layouts, and a theme toggle. All displayed business figures are sample demo data.

## Open locally

No package installation or build step is required. Open `index.html` directly in a modern browser, or serve this folder with any static web server.

## Deploy

Upload the contents of this folder to a static hosting service such as GitHub Pages. Set the publishing source to the repository root (or the folder containing `index.html`).

## Notes

This is the standalone HTML edition of the dashboard. Its CSS and JavaScript are included in `index.html`, so no local asset files or external runtime dependencies are required. Google Fonts are loaded from Google Fonts when internet access is available; system sans-serif fallbacks are used otherwise. Dashboard data is illustrative and is not connected to a backend, database, or live AI provider.
